# Film Diary

Film Diary for Windows: log what you watch, score it, keep lists, and see what Colin, Bryan and Brady have been watching.

## Install

1. Download [Film-Diary-Setup.exe](https://github.com/cpb09e-source/film-diary/releases/latest/download/Film-Diary-Setup.exe) and run it.
2. Windows may say "Windows protected your PC", because the app isn't code-signed. Press **More info**, then **Run anyway**.
3. Sign in with your first name. The first time, the password you type twice becomes yours.

After that it updates itself. When a new version has downloaded, the app asks you to restart.

This repo only holds the installers. The code is private.
