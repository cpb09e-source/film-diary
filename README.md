# Film Diary

Film Diary for Windows and Mac: log what you watch, score it, keep lists, and see what Colin, Bryan and Brady have been watching.

## Your login

| | Username | Password |
|---|---|---|
| Bryan | `bryan` | `bryan` |
| Brady | `brady` | `brady` |

The first time you sign in, type the password twice. Use the same one on any other computer you install it on, or sharing won't connect.

## Windows

1. Download [Film-Diary-Setup.exe](https://github.com/cpb09e-source/film-diary/releases/latest/download/Film-Diary-Setup.exe) and run it.
2. Windows may say "Windows protected your PC", because the app isn't code-signed. Press **More info**, then **Run anyway**.
3. Sign in.

## Mac

Apple silicon or Intel, macOS 13 or later.

1. Download [Film-Diary-Mac.dmg](https://github.com/cpb09e-source/film-diary/releases/latest/download/Film-Diary-Mac.dmg), open it, and drag Film Diary into Applications.
2. Open Film Diary. The Mac refuses the first time, because the app isn't from an identified developer. Open **System Settings > Privacy & Security**, scroll down to "Film Diary was blocked", and press **Open Anyway**.
3. Sign in.

After that it updates itself. When a new version has downloaded, the app asks you to restart.

This repo only holds the installers. The code is private.
